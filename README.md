# PORTFOLIO

A modern personal portfolio website built with React and Vite to showcase my skills, projects, and contact information.

## 🌐 Live Demo

**[View My Portfolio](https://portfolio-gold-two-35.vercel.app)**

## ✨ Features

- Responsive and modern portfolio design
- About Me section
- Skills and technologies
- Projects showcase
- Contact section
- Resume link
- Social media links
- Deployed with Vercel

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- HTML5
- CSS3
- Git & GitHub
- Vercel

## 🚀 Run Locally

Clone the repository:

`git clone https://github.com/Tushar-507/PORTFOLIO.git`

Go into the project directory:

`cd PORTFOLIO`

Install dependencies:

`npm install`

Start the development server:

`npm run dev`

Open the local URL shown in the terminal.
